# Peluquería y Barbería Adrián Millán · Huelva

Sitio web oficial y plataforma de reserva de cita previa de **Peluquería y Barbería Adrián Millán**, ubicada en Huelva, Andalucía.

## Características
- **Reserva de citas previa online**: Selección de barbero, servicio, día y franja horaria en intervalos de 10 minutos.
- **Panel de administración**: Gestión de agenda, citas del día, bloqueos de disponibilidad, servicios y personal.
- **Catálogo de productos y tienda**: Exposición de productos y promociones de barbería.
- **Galería de estilos**: Muestra de cortes, degradados fade y arreglos de barba.
- **SEO Local**: Optimización avanzada con Schema.org `BarberShop`, Geo-etiquetado en Huelva, Open Graph y PWA instalable.

## Tecnologías
- React 18 + TypeScript + Vite
- Tailwind CSS + Lucide Icons + GSAP / Motion
- Supabase (Autenticación y Base de Datos en tiempo real)
